# Hyun Ji — Research Portfolio

This folder contains the static files for the research portfolio.

## Publish with GitHub Pages

1. Create a new GitHub repository named `<your-github-username>.github.io`.
2. Set the repository to **Public**.
3. Upload the contents of this folder to the repository root. Upload `index.html`, `styles.css`, `script.js`, and the `writing-samples` folder—not the enclosing ZIP file.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. After GitHub finishes deploying, visit `https://<your-github-username>.github.io`.

Only the finalized, publicly shareable writing samples are included. Do not add private CV files, patent application documents, or internal project materials to a public repository.
